# FS25 Stop Time

Stop Time is a lightweight script mod for Farming Simulator 25 that lets you stop and resume the in-game clock by pressing the `0` key.

When time is resumed, the mod restores the time scale that was active before it was stopped.

## Features

- Stops the in-game time scale at exactly `0`.
- Resumes at the previously selected time scale.
- Works both on foot and while controlling a vehicle.
- Supports single-player, hosted multiplayer and dedicated servers.
- Restricts multiplayer use to the host or a logged-in server administrator.
- Displays an independent green status message beneath the upper-right HUD for four seconds.
- Includes English, German and French localisation.

## Controls

| Action | Default key |
| --- | --- |
| Stop or resume time | `0` |

The key is fixed and does not appear in the Farming Simulator 25 Controls menu.

## How it works

Press `0` once to set the time scale to `0` and stop the in-game clock. Press `0` again to resume at the time scale that was active beforehand.

For example, if the game is running at `5x` when time is stopped, it will return to `5x` when resumed.

## Multiplayer

- The host can stop or resume time.
- A remote player can use the mod after logging in as server administrator.
- A normal multiplayer client cannot change the time scale and receives an explanatory message.

## Installation

1. Download `FS25_StopTime.zip`.
2. Copy the ZIP into your Farming Simulator 25 `mods` folder.
3. Enable **Stop Time** when loading or creating a savegame.

Do not extract the ZIP before placing it in the `mods` folder.

## Compatibility

- Farming Simulator 25
- PC and Mac
- Single-player
- Hosted multiplayer
- Dedicated servers

Other mods that stop, change or extend the available time scales may conflict with Stop Time.
